
# MistiLoop Crochet

## Project Overview
An e-commerce application for handmade crochet products.

## Technology Stack
- Backend: NestJS
- Language: TypeScript
- Database: PostgreSQL
- ORM: Prisma

## Coding Conventions
- Use TypeScript types.
- Keep business logic in services.
- Keep HTTP request handling in controllers.
- Validate incoming request data.
- Use Prisma for database operations.
- Return clear and consistent error responses.

## Current Task
Build a product listing API supporting:
- Adding a product
- Getting all products
- Validating product name and price
